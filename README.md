## About This Repository

This repository contains the required submission files for the Master of Science in Computing dissertation: **Anti-PLUTO** (*Anti-Phishing Lexical Utilities and Threat Observation*). The project focuses on detecting both human-written and LLM-generated phishing emails using dual-branch semantic and stylometric features.

To keep the production Python package clean, this separate repository is provided specifically for thesis review.

---

## Files in This Repository

- **`antipluto/`**: Git submodule containing the full source code for the project, including the CLI, FastAPI service, preprocessing pipeline, classifier, and tests. It has its own `README.md` with full setup and usage instructions.
- **`Anti-PLUTO_MSc_Thesis.pdf`**: The complete Master's Thesis document in PDF format.
- **`screencast.mp4`**: A screen recording demonstrating the application, CLI commands, and API working.
